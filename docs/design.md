# Art direction

The selected direction pairs a paper masthead and oversized headline with a specimen of a vintage computer. Adil’s introduction is the first thing to read. The project archive begins directly below the opening spread. An individual work page gives the product’s actual interface enough space to inspect.

The following original studies are on the [Superdesign project canvas](https://superdesign.dev/teams/444f16a6-42a1-4bc8-bcff-3737f6e09947/projects/14d236ab-e0ff-4640-9c38-b452b9c8ef26). A [local responsive comparison](./design-canvas.html) can be opened offline.

| --- | --- | --- | --- |
| Originality | Gives an early desktop computer the prominence of a museum exhibit | Immediately recognizable shell metaphor | Personal publishing identity built around physical files |
| Typography | Heavy grotesk, a contrasting italic and modest mono captions establish three reading speeds | Uniform mono has a clear voice but flattens long-form hierarchy | Serif cover has presence, with utility labels on each file |
| Composition | Headline and computer balance across a wide spread | Commands lead directly to a dense directory | Diagonal file edge deliberately breaks the grid |
| Project presentation | A full-width sequence can alternate artwork and real product screens | Work index is fast to scan but shows little product evidence | File covers make good section transitions but delay seeing the product |
| Motion potential | Small monitor or preview changes can respond to input | Cursor and selection changes suit keyboard navigation | Opening the file invites a larger transition |
| Professional credibility | Clear authorship, quick access to work and room for source links | Developer audience will recognize the conventions immediately | Clear editorial voice, but the cover places Adil’s identity in a secondary role |
| Mobile usability | A simple headline, introduction, actions and artwork stack in order | Long routes need wrapping at narrow widths | The tilted cover takes space away from project copy |

## Design system

| Element | Direction for implementation |
| --- | --- |
| Foundation | Warm paper `#F1EBDD`, ink `#171717`, signal orange `#F15A24`, cobalt `#3155D9` and a sparing acid lime `#C7EF54`. Use ink on orange and lime controls. Reserve a deeper orange for small text on paper. |
| Display | Compact heavy sans for the identity statement. Give the closing word a contrasting editorial italic. Keep the heading as live text. |
| Reading | Use a sans text face at 16px or above, 1.45–1.65 line height. Set case-study sections in a narrower measure than the imagery. |
| Labels | Reserve mono for index labels, commands, metadata and control hints. Apply uppercase selectively. |
| Grid | Share outer margins across masthead, opening spread and project index. The desktop introduction occupies slightly more than half the spread. Linearize in semantic order on mobile. |
| Spacing | Work from 4, 8, 12, 16, 24, 32, 48, 64 and 96px increments. Use fluid section margins and fluid display sizes. |
| Edge and depth | Square image frames, 1px ink rules, a hard offset shadow for a pressed or raised control. Restrict faux scanlines and grain to artwork or a low-opacity texture. |
| Interaction | Underlined links, visible focus outlines, actual buttons for actions. Keep the pointer and keyboard paths equivalent. |
| Motion | Use short feedback on action or focus. Keep copy readable from first paint. Reduced-motion mode keeps the same destinations and information. |
| Case studies | Project title, short editorial introduction, capture with source credit, clearly labeled contribution and a route to the live product or source. |

## Research notes

- MotionSites’ VHS Archive and other public portfolio entries frame work through a recognizable physical format. This informed the experiment with a file sleeve and the decision to give a single object a central role in the selected design. [MotionSites portfolio library](https://studio.motionsites.ai/explore/vhs-archive)
- MotionSites’ Lumenvox Atelier walkthrough demonstrates choreography between the entrance headline and its visual subject. The archive uses that relationship in a static opening so visitors can navigate immediately. [MotionSites design walkthrough](https://www.motionsites.ai/lesson/build-animated-website-with-ai)
- Superdesign’s News Print and Terminal Flat studies show how a rule, an aligned edge and a clear type-size change can organize information. Those principles carry through to the case studies. [News Print](https://superdesign.dev/library/news-print) and [Terminal Flat](https://superdesign.dev/design-systems/terminal-flat)
- Superdesign’s retro portfolio prompt and ASCII hero provided examples of terminal labels and a keyboard-led reading order. The Phosphor index study tested how much of the interface could adopt that vocabulary. [Retro CRT portfolio](https://superdesign.dev/library/terminal-portfolio-website-retro-crt-phosphor-green-developer-portfolio) and [ASCII hero](https://superdesign.dev/library/ascii-hero)
